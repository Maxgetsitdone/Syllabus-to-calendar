# Syllabus to Calendar

Paste or upload a course syllabus and get every exam, quiz and due date as calendar events.
Review the list, then download an `.ics` file (Apple Calendar, Outlook, Google Calendar) or a Google Calendar CSV.

**Try it:** https://maxgetsitdone.github.io/Syllabus-to-calendar/

Everything runs in the browser; syllabi are never uploaded to a server. It can be installed on a phone with "Add to Home Screen".
